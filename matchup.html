How to read it

A rate is not a promise.

Three things are worth saying out loud, because a head-to-head invites all three to be misread.

The sample is fixed and published

Seeds come from one constant, 2654435761, using the same common-random-numbers trick the test suite uses. Run the same pair again and you get the same fights, second for second.

Which is not the same as fair

A champion that wins 60% of one particular series has won that series. Whether it is stronger overall is a question this page deliberately does not answer with a bigger number on the box.

Draws stay draws

Both fighters can still be standing when the clock runs out. Those are counted in their own column — never folded into a winner, because the engine did not name one.
